# numerical_guessing_game
## Числовая угадайка

Интерактивная веб-игра «Угадай число», написанная на Python с использованием фреймворка NiceGUI. Проект включает в себя кастомный стилизованный интерфейс, анимации, котика и проверку ввода данных.

## Структура проекта

* `static/` — папка со статическими ресурсами (картинки, графические элементы).
* `main_local.py` — точка входа для **локального запуска** приложения на компьютере.
* `main_host.py` — файл для **деплоя (развертывания) на облачном хостинге / веб-сервере** (например, Render).
* `numerical_guessing_game_without_gui.py` — консольная (CLI) версия игры без графического интерфейса.
* `requirements.txt` — список внешних библиотек и зависимостей, необходимых для работы проекта.

## Локальный запуск на вашем компьютере

Следуйте этой инструкции, чтобы запустить приложение у себя на ПК.

### 1. Скачивание репозитория

Откройте терминал / командную строку и клонируйте репозиторий:

```bash
git clone [https://github.com/Tanya-de-pro/numerical_guessing_game.git](https://github.com/Tanya-de-pro/numerical_guessing_game.git)
```

Перейдите в папку проекта:

```bash
cd numerical_guessing_game
```

Если вы скачали проект ZIP-архивом, распакуйте его, откройте терминал (или командную строку) и перейдите в папку с проектом.


### 2. Создание виртуального окружения

**Windows:**

```bash
python -m venv .venv
```

**Linux / macOS:**

```bash
python3 -m venv .venv
```


### 3. Активация виртуального окружения

**Windows (Command Prompt / CMD):**

```bash
.venv\Scripts\activate
```

**Windows (PowerShell):**

```powershell
.\.venv\Scripts\Activate.ps1
```

**Linux / macOS:**

```bash
source .venv/bin/activate
```

После активации виртуального окружения в начале строки терминала появится название окружения в скобках, например:

```text
(.venv) C:\Users\User\numerical_guessing_game>
```


### 4. Установка зависимостей

Установите все необходимые библиотеки из файла `requirements.txt`:

```bash
pip install -r requirements.txt
```

Дождитесь завершения установки всех зависимостей.


### 5. Запуск локальной версии

**Windows:**

```bash
python main_local.py
```

**Linux / macOS:**

```bash
python3 main_local.py
```

После запуска приложение станет доступно в браузере по адресу:

**http://localhost:8080**

Откройте этот адрес в любом браузере и начните игру.
